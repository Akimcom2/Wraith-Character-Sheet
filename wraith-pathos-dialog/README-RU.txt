Wraith: Pathos in Arcanos Roll
================================

Версия 1.0.5
-------------

Исправлено перекрытие блока Пафоса секцией «Сложность». Чекбокс и поле
стоимости теперь доступны для клика, а окно автоматически пересчитывает высоту.

Использование Пафоса добавляется только в окно броска Арканоса с разделами
«Описание» и «Система». В обычных бросках характеристик и способностей блок
Пафоса больше не появляется.

Нативный чекбокс заменён независимым переключателем, на который не влияют
обработчики формы WoD20. Блок Пафоса выровнен по ширине соседних секций.

Исправления названий теперь применяются при открытии листа и при переключении
его вкладок. Также учтён вариант опечатки «Жизень».

Исправленные названия теперь отображаются и в окнах бросков, включая заголовок
и формулу пула костей. Название «Арканои» восстановлено по просьбе мастера.

Поле стоимости Пафоса изолировано от автоматической перерисовки формы WoD20,
поэтому значения больше 1 сохраняются до броска. Ширина блока синхронизируется
с секцией «Сложность».

Исправлены русские подписи на листе призрака без изменения внутренних данных:

* «Привлекательность» → «Внешность»;
* «Бюрократия» → «Законы»;
* «Жезнь» или «Жизень» → «Жизнь».

Модуль добавляет в окно броска Арканоя, рядом с использованием Силы воли:

* флажок «Использовать Пафос»;
* поле «Стоимость»;
* текущий доступный запас Пафоса.

При нажатии «Бросок» модуль проверяет запас, списывает указанное количество
из system.advantages.pathos.temporary и только затем запускает бросок.
Если Пафоса недостаточно, бросок отменяется.

Установка
---------

1. Распакуйте папку wraith-pathos-dialog в Foundry Data/modules/.
2. Перезапустите Foundry VTT.
3. В мире откройте «Управление модулями» и включите
   «Wraith: Pathos in Arcanos Roll».
4. Обновите страницу у мастера и игроков (F5).

Важно
-----

Окно броска должно знать персонажа. Для игрока это обычно принадлежащий ему
персонаж или выбранный токен. Мастеру перед вызовом Арканоя следует выделить
токен нужного призрака, если окно системы не передаёт актёра напрямую.

Проверено по структуре данных WoD20; совместимость заявлена для Foundry 12–13.
