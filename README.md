# Wraith: Pathos in Arcanos Roll

Модуль для Foundry VTT и системы WoD20, предназначенный для игры по **Wraith: The Oblivion**.

Он добавляет расход Пафоса непосредственно в окно применения Арканоя, исправляет несколько русских подписей листа персонажа и сохраняет совместимость с существующими актёрами.

Проект используется в кампании **«Призраки / Зеркалье»** и развивается как отдельный модуль совместимости для WoD20. Репозиторий служит основной точкой хранения исходного кода, документации и истории изменений модуля.

## Текущая версия

**1.0.5**

- минимальная версия Foundry VTT: **12**;
- проверенная версия Foundry VTT: **13**;
- система: **WoD20**;
- изменение шаблонов и файлов самой системы не требуется.

## Возможности

### Расход Пафоса при применении Арканоя

В окно броска Арканоя добавляются:

- переключатель **«Использовать Пафос»**;
- числовое поле **«Стоимость»**;
- индикатор доступного запаса Пафоса.

При нажатии **«Бросок»** модуль:

1. Проверяет, включено ли использование Пафоса.
2. Проверяет введённую стоимость.
3. Сравнивает стоимость с текущим запасом персонажа.
4. Списывает указанное количество Пафоса.
5. Запускает исходный бросок WoD20.

Если Пафоса недостаточно, бросок отменяется и выводится уведомление.

Пафос не списывается при закрытии окна или при выключенном переключателе.

### Только броски Арканоев

Панель расходования появляется только в полном окне Арканоя, содержащем разделы **«Описание»** и **«Система»**.

Она не добавляется к обычным броскам:

- характеристик;
- способностей;
- Интеллекта, Ловкости, Смекалки и других параметров персонажа.

### Исправленные русские подписи

Модуль визуально заменяет следующие названия:

| Исходное название | Отображаемое название |
|---|---|
| Привлекательность | Внешность |
| Бюрократия | Законы |
| Жезнь / Жизень | Жизнь |

Название **«Арканои»** сохраняется без изменений.

Исправленные названия отображаются:

- на листе персонажа;
- после переключения вкладок листа;
- в заголовках окон бросков;
- в формулах пула костей.

Изменения являются только визуальными. Внутренние ключи WoD20 и сохранённые значения персонажей не изменяются.

## Установка

### Установка из архива

1. Остановите Foundry VTT.
2. Распакуйте каталог `wraith-pathos-dialog` в:

   ```text
   FoundryVTT/Data/modules/
   ```

3. Запустите Foundry VTT.
4. Откройте нужный мир.
5. Перейдите в **Управление модулями**.
6. Включите **Wraith: Pathos in Arcanos Roll**.
7. Обновите страницу мастера и игроков сочетанием `Ctrl+F5`.

Итоговый путь к манифесту должен выглядеть так:

```text
FoundryVTT/Data/modules/wraith-pathos-dialog/module.json
```

### Обновление

1. Остановите Foundry VTT.
2. Удалите старый каталог `wraith-pathos-dialog` из `Data/modules`.
3. Распакуйте на его место новую версию.
4. Запустите Foundry VTT.
5. Выполните `Ctrl+F5`.

Настройки мира и данные персонажей при обновлении не затрагиваются.

## Использование

1. Откройте лист призрака.
2. Перейдите на вкладку **«Арканои»**.
3. Откройте бросок нужной способности Арканоя.
4. Включите **«Использовать Пафос»**.
5. Укажите стоимость — например, `2` или `3`.
6. Нажмите **«Бросок»**.

После успешного списания появится уведомление:

```text
Пафос: −2 (1 осталось)
```

## Определение персонажа

Модуль пытается получить актёра в следующем порядке:

1. Актёр, переданный окном броска.
2. Владелец предмета или способности.
3. Выделенный токен на активной сцене.
4. Персонаж, назначенный текущему пользователю.

Если мастер вызывает Арканой из окна, которое не передаёт актёра напрямую, перед броском следует выделить токен нужного призрака.

## Хранение Пафоса

Основной путь ресурса в данных актёра:

```text
system.advantages.pathos.temporary
```

Для совместимости также поддерживается:

```text
system.advantages.pathos.value
```

## Структура модуля

```text
wraith-pathos-dialog/
├── module.json
├── README-RU.txt
├── scripts/
│   └── pathos-dialog.js
└── styles/
    └── pathos-dialog.css
```

- `module.json` — манифест Foundry VTT;
- `scripts/pathos-dialog.js` — определение окон, интерфейс, проверка и списание Пафоса;
- `styles/pathos-dialog.css` — оформление панели расходования;
- `README-RU.txt` — краткая инструкция для архива.

## Технические особенности

- Модуль использует хуки приложений Foundry VTT поколений V1 и V2.
- Окно Арканоя определяется по разделам `Описание`/`Description` и `Система`/`System`.
- Переключатель Пафоса реализован независимо от штатных чекбоксов WoD20.
- Поле стоимости изолировано от автоматического обновления формы WoD20, поэтому введённое значение не сбрасывается на `1`.
- Ширина панели синхронизируется с секцией сложности броска.
- Переименования интерфейса повторно применяются при динамической перерисовке и переключении вкладок.

## Проверка после установки

Рекомендуемый короткий тест:

1. Открыть лист призрака и проверить названия **«Внешность»**, **«Законы»**, **«Жизнь»** и **«Арканои»**.
2. Выполнить обычный бросок Внешности — панели Пафоса быть не должно.
3. Открыть бросок Арканоя — панель Пафоса должна появиться.
4. При запасе не менее 3 указать стоимость `2`.
5. Включить переключатель и выполнить бросок.
6. Убедиться, что списано ровно 2 Пафоса.
7. Попробовать указать стоимость выше запаса — бросок должен быть отменён.

## Известные ограничения

- Модуль рассчитан на текущую структуру окон WoD20. После крупных обновлений системы могут потребоваться новые селекторы.
- Если окно броска не передаёт актёра, мастер должен выделить соответствующий токен.
- Автоматическая установка по URL манифеста не настроена. Для неё потребуется разместить `module.json` и ZIP-релиз на GitHub.

## Сообщение об ошибке

При создании issue желательно приложить:

- версию Foundry VTT;
- версию WoD20;
- версию модуля;
- скриншот окна;
- сообщения из консоли браузера (`F12` → `Console`);
- описание ожидаемого и фактического поведения.
